# Epileptic Seizure Detection Algorithms Benchmarking

This repository contains a project developed as part of the **CS-433 Machine Learning** course at [EPFL](https://www.epfl.ch/), supervised by the **Embedded Systems Laboratory (ESL)**.

## Project Overview

The project aims to implement, evaluate, and benchmark different machine learning and deep learning algorithms for epileptic seizure detection using electroencephalography (EEG) data.

The main objectives are to:
- Review existing and recent seizure detection algorithms.
- Implement and train selected models on EEG datasets.
- Compare model performance using appropriate evaluation metrics.

## Datasets

Potential publicly available datasets include:
- [Epileptic Seizure Recognition Dataset](https://www.kaggle.com/datasets/harunshimanto/epileptic-seizure-recognition)
- [CHB-MIT Scalp EEG Database](https://physionet.org/content/chbmit/1.0.0/)
- [Bonn EEG Dataset](https://www.upf.edu/web/ntsa/downloads)

The final datasets and benchmarking methodology are yet to be determined.
